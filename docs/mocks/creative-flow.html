The creative flow

v1 · 2026-08-09 · spec: the-garden-product-plan.md §2–4 · tokens: rebrand handoff

Eight screens, one persona, one arc: sit in without an account → belong → post → get a response → hit the seat gate at a moment of intent → pay $10 → start the work → apply to paid work. Every gate names the locked value, says why now, shows the path, and leaves an exit.

S1An open table, public — no account

The handoff's highest-leverage onramp: browsable without signup. Table card is the near-spec component (handoff Task 3). Capability: table.join.open — visitor ✓. The Garden is the default host org, so the org line says THE GARDEN, not Abiding Practice (§6).

S4First proof — a person, not a like

The onramp promise: a real response within a week. No like counts anywhere (no-algorithm position). Instrumentation behind this screen: if a first post has zero responses at day 5, alert the table's host — silence in week one is a product failure, not a user failure.
