The event that widens the tent: a real conversation, posted publicly in the platform, sent beyond Rick, David, Haley, and Joseph. Designed outsider-first — no account to see it, one field to say you're coming, and the page itself quietly explains what this place is. If a stranger can land here from a text message and feel invited rather than marketed to, Phase 0 passes.

E1The public event page — a stranger's first screen

Fully public, server-rendered, OG-tagged — it must unfurl beautifully in a text message (Task 1). The settings block reuses the table card's credit idiom. Capacity honest, attendance framed as deeds ("18 coming"), never hype. The what-is-this-place module is where curiosity converts — one paragraph, one link, no pitch.

E4The morning after — the only follow-up

One email, the day after, from the hosts by name — not a sequence. It does three things: thanks, shows one real thing that happened (a photo, a connection made), and opens exactly one door matched to what the person is (the persona question, asked now, when it's earned). This is where an attendee becomes a member.
