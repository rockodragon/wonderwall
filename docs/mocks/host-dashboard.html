The host dashboard

v1 · 2026-08-09 · phase 3 · designed against the question: what does a host need at 7 AM on gathering day?

Four jobs, four panels: who's new (greet them by name), who's coming (set the right number of chairs), what moved (money they can trust at a glance), and who's missing (the pastoral affordance no other tool has). Operational counts live here legitimately — they're deeds the host acts on, never public scoreboard. Nothing on this page ranks a person.

D1Today — the glanceable morning

Self-critique applied: a first draft led with vanity totals (members all-time, projects launched). Cut — a host acts on this week: tonight's count, this week's new people, money that moved, and the one thing needing a decision (an application). Anything that can't change a host's next hour doesn't belong on screen one.

D4Money — a ledger the host can read aloud

The whole month in one column: what the community's dues generated (with the 40/50/10 receipt), what the host's paid table collected, the garden's 10%, the payout. Ledger kinds match the accounting spec (membership_dues, host_fee, project_contribution, seat_sponsorship). Self-critique: no charts here on purpose — a host needs numbers they can repeat to their board from memory, not a dashboard to interpret.
